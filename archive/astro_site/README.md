# Deprecated Astro Landing Page

This directory contains the pre-Flutter Fun App landing-page implementation.
It is retained only as historical design, content, and implementation reference.

The archive is not part of the active application, is not built by CI, and is
not deployed. New production work must be implemented in Flutter. Do not patch
the archived Astro site to change production behavior; Git history remains the
authoritative record of its original evolution.
